# Persistent Inequalities in Air Quality Across Municipalities in Santiago, Chile: 2022–2024

This repository contains the code and data structure used to analyze the spatiotemporal trajectories of fine particulate matter (PM2.5) pollution across 10 municipalities in the Santiago Metropolitan Region, Chile. 

The project evaluates the impact of sociodemographic variables (multidimensional poverty, population density) and seasonal factors (winter-biomass interaction) on PM2.5 concentrations, contrasting national regulatory compliance with US Environmental Protection Agency (EPA) and World Health Organization (WHO) guidelines.

## 📂 Repository Structure

The project follows a structured workflow to ensure the reproducibility of the analysis:

* **`input/`**: Contains raw and processed data.
    * `data_raw/`: Original `.csv` files with hourly PM2.5 records per monitoring station (SINCA).
    * `data_processed/`: Cleaned and consolidated `.rds` datasets (`datos_analisis_final.rds` for the v1.0 pipeline, `datos_analisis_final_2.0.rds` for the current v2.0 pipeline).
    * `shp_SINCA/`: Vector files (shapefiles) of the monitoring stations.
* **`output/`**: Results generated by the scripts.
    * `tables/`: Descriptive statistics, completeness, healthy days, and mixed model results (`.csv`, `.md`, `.xlsx`). Current (v2.0) tables carry a `_2.0` suffix; earlier v1.0 outputs are kept for reference under `tables/v1/`.
    * `figures/`: Spatial maps (`.png`) of concentrations, 98th percentile, and regulatory compliance, overall and by winter period. Current (v2.0) maps carry a `_2.0` suffix; earlier v1.0 maps are kept for reference under `figures/v1/`.
* **`processing/`**: R scripts that make up the analysis pipeline.
    * `analisis2.0/`: **Current pipeline**, used for the published manuscript (see "Workflow" below).
    * `analisis1.0/`: Earlier pipeline, kept for reference/reproducibility of prior results; superseded by `analisis2.0/` (see "Pipeline versions" below).

## ⚙️ Workflow (Pipeline) — `processing/analisis2.0/`

The current analysis is divided into the following sequential scripts:

1.  **`00_setup_functions.R`**: Loads libraries, defines spatial color palettes, manual sociodemographic data (CASEN 2022 poverty estimates / Census 2024), and shared functions — including daily/monthly/annual data-validity criteria based on Decreto 61/2008 (MINSAL) and Decreto 12/2011 (MMA).
2.  **`01_load_clean.R`**: Reads and standardizes the 10 raw station databases, calculates daily averages, applies the regulatory completeness criteria (daily ≥18 continuous hours; monthly ≥75% of scheduled days; annual ≥11 valid months, or 9–10 with imputation), and consolidates the master dataset used by all downstream scripts.
3.  **`02_descriptive_analysis.R`**: Generates annual and winter descriptive statistics, flagging non-compliant station-years/winters. Year-to-year comparisons use non-parametric, pseudo-replication-safe tests on monthly means (Wilcoxon signed-rank for municipalities with 2 compliant years, Friedman for 3) instead of a daily one-way ANOVA.
4.  **`02.1_Sensitivity_analysis.R`**: Targeted sensitivity check of the year-comparison tests (paired t-test/Wilcoxon and repeated-measures ANOVA/Friedman) for the municipalities that were significant under the original daily ANOVA.
5.  **`02b_healthy_days_table.R`**: Calculates the proportion of "Healthy Days" per station-year and station-winter against the regulatory limits of Chile (50 µg/m³), the US EPA (35 µg/m³), and the WHO (15 µg/m³).
6.  **`03_mixed_models.R`**: Fits Linear Mixed Models (LMM) for daily PM2.5, including a fully adjusted model (year, season, poverty, density, altitude, biomass heating, and a winter × biomass interaction) refit with an AR(2) autoregressive residual correlation structure to account for serial autocorrelation (selected over AR(1) via likelihood-ratio test). Includes sensitivity analyses excluding Talagante (leave-one-out), and excluding poverty or biomass heating, to assess robustness and disentangle the two.
7.  **`04_spatial_analysis_maps.R`**: Spatial integration using the elevation API and the `chilemapas` package. Generates the study area cartography and the geographic distribution of regulatory compliance, P98, and annual/winter averages — using the same completeness criteria as the tables (non-compliant station-years/winters are mapped as missing).

### Pipeline versions

`processing/analisis1.0/` contains the original pipeline (naive daily-level ANOVA, no explicit data-completeness criterion, LMM without autocorrelation correction). `processing/analisis2.0/` supersedes it, applying the regulatory completeness criteria and addressing peer-review feedback on autocorrelation and statistical power. All results reported in the manuscript come from `analisis2.0/`.

## 🛠️ Technical Requirements

The analysis was developed in **R**. To replicate the environment, the following main libraries are required:

* **Data Manipulation:** `dplyr`, `tidyr`, `lubridate`, `readr`, `janitor`, `purrr`.
* **Statistical Modeling:** `lme4`, `lmerTest`, `nlme` (autoregressive/AR(2) models), `broom.mixed`, `performance`.
* **Spatial Analysis & Visualization:** `sf`, `chilemapas`, `ggplot2`, `elevatr`, `ggspatial`, `shadowtext`.
* **Output:** `knitr`, `writexl`.
